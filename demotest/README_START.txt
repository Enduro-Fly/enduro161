ENDURO 161 — прокат эндуро мотоциклов

Запуск на Windows:
1. Распакуйте архив.
2. Откройте терминал в папке demotest (там, где manage.py).
3. Установите Django, если его нет: py -m pip install "Django>=5.2,<6.0"
4. Примените миграции: py manage.py migrate
5. Запустите сайт: py manage.py runserver
6. Откройте http://127.0.0.1:8000/

Функции:
- Главная страница с каталогом эндуро мотоциклов.
- Регистрация и вход через Django Auth.
- Создание бронирования: мотоцикл, дата/время, длительность, способ оплаты.
- Расчёт цены по тарифу и длительности.
- Проверка пересечения бронирований одного мотоцикла.
- Личный кабинет со списком броней и отменой ожидающей брони.
- Возможность оставить отзыв по завершённой брони.
- Управление бронями и статусами через /admin/.

Первый запуск использует существующую SQLite базу проекта. Команда migrate добавит необходимые поля. Для доступа к /admin/ создайте администратора:
py manage.py createsuperuser

Примечание: цены и состав парка — демонстрационные, их можно изменить в testapp/views.py и testapp/models.py. Перед публичным размещением установите DEBUG=False, задайте безопасный SECRET_KEY и настройте ALLOWED_HOSTS.
